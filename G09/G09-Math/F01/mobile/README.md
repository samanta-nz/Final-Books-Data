## چیدمان (روی خود عکس پس‌زمینه اندازه‌گیری شده)
| ناحیه | موقعیت |
|---|---|
| کادر عنوان درس | ۵٫۸٪ تا ۱۲٪ ارتفاع |
| تختهٔ سفید | ۱۸٫۲٪ تا ۴۷٫۶٪ |
| کادر متن جاری (۳ سطر) | ۵۳٫۶٪ تا ۶۶٫۴٪ |
| نوار کنترل + دراپ‌داون بخش‌ها | ۸۸٫۵٪ تا ۹۳٫۹٪ |

استیج با نسبت ۹۰۱:۱۷۴۶ ساخته می‌شود و کل ارتفاع صفحهٔ موبایل را می‌گیرد؛ روی نسبت‌های
۱۹٫۵:۹ و ۲۰:۹ و ۱۶:۹ هم هم‌تراز می‌ماند. `safe-area`، بدون زوم، بدون اسکرول صفحه.

## رفتار
- با شروع هر بخش، تخته از نو ساخته می‌شود: عنوان بخش + اولین سطر همان لحظه؛ سپس سطرها
  به ترتیب و هم‌زمان با صدا کشیده می‌شوند و تا شروع بخش بعدی روی تخته می‌مانند.
- تخته هیچ‌وقت خالی نیست (نه در باز شدن، نه بین بخش‌ها، نه در حالت توقف).
- کادر متن فقط ۳ سطر نشان می‌دهد و خودکار اسکرول می‌شود؛ جملهٔ در حال خواندن در سطر میانی
  پررنگ است.
- کنترل‌ها: پخش/توقف، بخش قبل/بعد، دراپ‌داون همهٔ بخش‌ها، زمان سپری‌شده.
- محتوا بدون متن یا علامت اضافه است؛ فقط عنوان درس، محتوای تخته، ۳ سطر متن و کنترل‌ها.

## بازسازی
```bash
pip install av numpy pillow
python tools/slides_timing.py G09/G09-Math/F01        # زمان‌بندی بخش‌ها/جمله‌ها
python tools/build_mobile.py G09/G09-Math/F01         # ساخت این فایل‌ها + index
python tools/build_mobile.py G09/G09-Math/F01 --bitrate 24000   # صدا سبک‌تر
```
صدا با ۳۲ کیلوبیت بر ثانیه Opus و پس‌زمینه به‌صورت JPEG کیفیت ۸۲ در فایل امبد می‌شوند.
سافاری آیفون Ogg/Opus را پخش نمی‌کند (این محدودیت خود فایل‌های `.ogg` مخزن است)؛
کروم اندروید/دسکتاپ و فایرفاکس بدون مشکل پخش می‌کنند.
