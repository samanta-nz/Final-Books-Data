# نسخهٔ موبایل اصلاح‌شده — فصل دوم ریاضی نهم

هر درس یک HTML مستقل و آفلاین با صدای AAC، فونت و تصویر جاسازی‌شده است.

- متن با زمان واژه‌های صوت هم‌تراز شده است.
- نکته‌های تخته تألیفی‌اند و زمان هر نکته از عبارت مرتبط در گفتار می‌آید.
- تخته بر اساس اندازهٔ قاب صفحه‌بندی می‌شود؛ صفحه‌های ظاهرشده از پایین تخته قابل مرورند.
- سه سطر متن دیده می‌شود. برگشت پخش، تخته را مطابق زمان مقصد بازسازی می‌کند.
- تعریف‌ها، شرط‌ها و فرمول‌ها کامل و عبارت‌های ریاضی در محدودهٔ چپ‌به‌راست نمایش داده می‌شوند.

برای بازسازی از داده‌های همین مخزن:

```bash
python -m pip install -r tools/requirements-mobile.txt
python tools/build_mobile.py G09/G09-Math/F02
```

FFmpeg باید نصب باشد. برای بازسازی صوتی و آزمون‌ها، راهنمای `MOBILE-FIXES.fa.md` در ریشهٔ مخزن را ببینید.
