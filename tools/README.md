# مجموعهٔ تولید درس موبایل فارسی

این ابزارها نسخهٔ استفاده‌شده برای ۹ درسِ اصلاح‌شدهٔ ریاضی نهم هستند و در همین مخزن برای درس‌های بعدی نگهداری می‌شوند. مبنای کیفیت، متن اصلی، هم‌ترازی واژه‌ها، تألیف نکته‌ها و شکل‌ها با لنگر گفتاری و بررسی شنیداری نمونه‌هاست. اجرای خودکار به‌تنهایی جای بازبینی محتوای کتاب و شنیدن صدا را نمی‌گیرد.

## اجزای ذخیره‌شده

| ابزار | وظیفه |
|---|---|
| `mobile_pipeline.py` | اجرای مراحل آماده‌سازی، سینک، ساخت، بررسی و بسته‌بندی با مسیر دلخواه درس یا فصل |
| `align_ogg.py` | ساخت زمان‌بندی اولیه از متن بخش‌بندی‌شده و OGG؛ این مرحله هنوز سینک دقیق نیست |
| `align_asr.py` | تشخیص گفتار فارسی و لنگرهای واژه‌ای، همراه کشِ قابل ادامه |
| `refine_asr.py` | بازشناسی فاصله‌ها و نقاط مشکوک |
| `force_align.py` | هم‌ترازی اجباری متن اصلی با پنجره‌های صوتی هم‌پوشان؛ حفظ املای متن اصلی |
| `build_mobile.py` | ساخت HTML مستقل و آفلاین، همراه فونت، تصویر، فرمول، داده‌ها و OGG اصلی بدون تبدیل |
| `mobile_template.html` | چیدمان وایت‌برد، متن سه‌سطره و کنترل‌های صوتی |
| `mobile_player.js` | ساعت مشترک متن/تخته/صدا، اسکرول خودکار سه سطر، صفحه‌بندی وایت‌برد، سیک، لمس طولانی ±۵ ثانیه، سرعت پخش و بازیابی وضعیت در تغییر اندازه |
| `math_notation.js` و `math-assets/` | فرمول‌نویسی کتابی آفلاین: کسر عمودی، رادیکال، توان و نمادها با KaTeX و مجوز آن |
| `mobile_audio.py` | خواندن OGG و اعمال نگاشت ویرایش‌های صوتی برای تحلیل؛ فایل اصلی خروجی عیناً امبد می‌شود |
| `verify_mobile.py` | بررسی خودکار هر درس در دو اندازهٔ موبایل، فرمول و رقم‌ها، کنترل‌ها، سه سطر متن، درخواست شبکه و تطابق OGG |
| `test_mobile.py` و `testdata/` | نمونه‌های رگرسیون محتوایی و شنیداریِ ۹ درس مرجع |
| `preview_server.py` | پیش‌نمایش با پشتیبانی HTTP Range |

## نصب و اجرا

پیش‌نیاز سیستم: Python 3.10 یا بالاتر، FFmpeg و مرورگر Chromium. تشخیص گفتار در اجرای اول مدل Whisper را دانلود می‌کند؛ خروجی درس به اینترنت وابسته نیست.

```bash
python -m pip install -r tools/requirements-mobile.lock.txt
python -m playwright install chromium
```

ساختار هر درس در فصل دلخواه، مثلاً `G09/G09-Math/F03/0301`:

```text
0301.ogg            صدای اصلی
0301.txt            متن اصلی با عنوان‌ها و بخش‌های ##
0301.timing.json    زمان‌های جمله/واژه و بخش‌ها
0301.board.json     نکات و شکل‌های تألیف‌شده با لنگر گفتاری
```

مراحل برای فصل جدید (به‌جای مسیر نمونه، مسیر واقعی بدهید):

```bash
python tools/mobile_pipeline.py G09/G09-Math/F03 --stage init
python tools/mobile_pipeline.py G09/G09-Math/F03 --stage align
# اکنون متن/زمان‌ها را بررسی و فایل‌های board.json را تألیف کنید.
python tools/mobile_pipeline.py G09/G09-Math/F03 --stage build
python tools/mobile_pipeline.py G09/G09-Math/F03 --stage verify
python tools/mobile_pipeline.py G09/G09-Math/F03 --stage package --output output/F03-mobile.zip
```

برای یک درس، مسیر فایل OGG را بدهید. `init` فایل زمان‌بندی موجود را بازنویسی نمی‌کند. `align` زمان‌بندی را تغییر می‌دهد؛ قبل از اجرای دوباره، تغییرات بررسی‌شده را در گیت ذخیره کنید. کشِ جداگانهٔ هر درس در `.cache/mobile-alignment` نگهداری می‌شود و قابل تغییر با `--cache` است. برای مرورگر سیستم از `--browser /usr/bin/chromium` در مرحلهٔ verify و برای پس‌زمینهٔ دیگر از `--bg` در build و package استفاده کنید.

## تألیف وایت‌برد و شکل‌ها

برای هر بخشِ زمان‌بندی، یک مدخل در `sections` بسازید. `sentence` شمارهٔ صفرمبنای جمله در `timing.json` و `anchor` عبارتِ دقیق موجود در همان جمله است؛ سازنده زمان واژهٔ آن را استخراج می‌کند. متن تابلو خلاصهٔ استاندارد نکته باشد. مثال ساختار:

```json
{
  "version": 1,
  "sections": [{
    "section": 0,
    "title": "عنوان بخش",
    "items": [{
      "sentence": 0,
      "anchor": "عبارت دقیق همان جمله",
      "text": "کسرهای هم‌ارز: `1/2=2/4`.",
      "diagram": {
        "type": "line",
        "points": [{"x": 180, "text": "1/2 = 2/4", "closed": true}],
        "label": "کسرهای هم‌ارز روی یک نقطه"
      }
    }]
  }]
}
```

این فقط نمونهٔ ساختار است؛ تعداد بخش‌ها و عبارت لنگر باید مطابق درس واقعی تنظیم شوند. نمونه‌های کامل و بررسی‌شده در فایل‌های `G09/G09-Math/F01/*.board.json` و `F02/*.board.json` موجودند.

نوع شکل‌های آماده: `single`، `venn`، `nested`، `subset`، `disjoint`، `boxes`، `table`، `grid`، `line`، `axis`، `distance`، `triangle`، `construction`، `spinner` و `outcomes`. پارامترهای هرکدام در تابع `diagram` در `mobile_player.js` تعریف شده‌اند. برای تغییر مرحلهٔ شکل، یک نکتهٔ تازه با همان نوع شکل و پارامترهای مرحلهٔ جدید به جملهٔ مربوط متصل کنید. همهٔ اشاره‌های واقعی به شکل‌ها بررسی شوند؛ وتر و رسم نمودار فقط نمونه‌اند.

قواعد ثابت: رقم فارسی، Vazir Bold واقعی، نوشته‌های مشکی/آبی/سبز/قرمز، کسر عمودی و توان و رادیکال استاندارد، سه سطر اتواسکرول، نوار سیک، کلیک برای بخش قبل/بعد و لمس طولانی برای ±۵ ثانیه، پخش ۱۰٪ کوچک‌تر. جزئیات در [قواعد پروژه](../G09/G09-Math/AGENTS.md) ذخیره شده‌اند.

## کنترل کیفیت و نگهداری

- همهٔ جمله‌ها، واژه‌ها و لنگرها باید در زمان صدا و بخش درست باشند. پس از اجرای alignment، آغاز/میانه/پایان هر درس و نمونه‌های مشکل‌دار را با شنیدن صدا بررسی کنید؛ عقب‌وجلو رفتن نیز باید متن و شکل درست را بازیابی کند.
- بازه‌های مشکوک، گفتار تکراری و تفاوت متن با صدای واقعی را بررسی کنید. حذف یا پرش صوتی تنها برای مورد بررسی‌شده در `audio-edits.json` ثبت شود؛ تنظیم یک درس را خودکار به درس دیگر کپی نکنید.
- شکل‌ها از نظر عضوها، عددها، جهت محور، مرز باز/بسته، ناحیهٔ رنگی و ترتیب ساخت با متن تدریس/کتاب تطبیق داده شوند. ابزار مرورگر، درستی ریاضی یا شنیداری را تضمین نمی‌کند.
- `verify` خروجی را در دو اندازهٔ ۳۹۰×۸۴۴ و ۳۶۰×۶۴۰ بررسی می‌کند و در صورت مشکل با خطا متوقف می‌شود. گزارش پیش‌فرض در `output/mobile-verification.json` ذخیره می‌شود. فایل گزارش همراه خروجی بایگانی شود.
- فونت‌های اصلی در `G09/G09-Math/F01/mobile/fonts` و پس‌زمینه در ریشهٔ مخزن هستند. برای استفادهٔ مستقل، پوشهٔ `fonts` را کنار پوشهٔ `tools` و تصویر را در همان ریشه قرار دهید؛ بستهٔ خروجی این فایل‌ها را در `sources` نگه می‌دارد.
- فایل‌های OGG، TXT، timing، board، استثناهای caption/audio، ابزارها و گزارش‌های هر نسخه در گیت نگهداری شوند؛ کش مدل/بازشناسی را در مخزن قرار ندهید.

برای درس‌های موجود نیازی به اجرای مجدد تشخیص گفتار نیست؛ زمان‌بندی تأییدشده را حفظ و از مرحلهٔ build استفاده کنید.

نسخه‌های محیط مرجع در `reference-versions.json` و `requirements-mobile.lock.txt` ثبت شده‌اند. فایل `requirements-mobile.txt` فهرست وابستگی‌ها بدون قفل نسخه است. برای گرفتن بستهٔ مستقل ابزارها:

```bash
python tools/export_mobile_toolkit.py --output output/Persian-Mobile-Lesson-Toolkit.zip
```
