# ابزارها

| فایل | کار |
|---|---|
| `align_ogg.py` | هم‌ترازی متن گفتار (`txt`) با صدا (`ogg`): پاکت انرژی ۱۰ms، تشخیص مکث، قیدزدن مرز جمله‌ها روی پایان مکث با DP |
| `slides_timing.py` | نگاشت بخش‌های متن و اسلایدهای وایت‌بورد روی خط زمان → `NNNN.timing.json` |
| `build_mobile.py` | ساخت فایل موبایل تک‌فایلی (پس‌زمینه base64 + صدا base64 + دادهٔ زمان‌بندی) → `mobile/NNNN.html` |
| `preview_server.py` | سرور استاتیک با پشتیبانی Range (برای تست در مرورگر) |
| `make_report.py` | گزارش فارسی زمان‌بندی |

```bash
pip install av numpy pillow

python tools/slides_timing.py G09/G09-Math/F01      # یا مسیر یک درس: .../0101
python tools/build_mobile.py G09/G09-Math/F01       # همهٔ درس‌ها + index.html
python tools/preview_server.py G09/G09-Math/F01 8099
```

## روش همگام‌سازی (بدون ASR)
۱. رمزگشایی ogg به ۱۶kHz مونو و پاکت RMS ۱۰ میلی‌ثانیه‌ای.
۲. آستانهٔ سکوت تطبیقی (صدک ۱۲ + ۳dB) → فهرست مکث‌ها.
۳. تقسیم متن به جمله با وزن گفتاری (تعداد حروف بی‌فاصله).
۴. نگاشت خطی وزن تجمعی روی زمان باصدا، سپس DP یکنوا که مرز جمله‌ها را روی **پایان مکث**
   (لحظهٔ برگشتن صدا) قید می‌زند؛ خط زمان بین لنگرها تکه‌ای‌خطی بازسازی می‌شود.
۵. تطبیق یکنوای اسلایدهای `sc(...)` وایت‌بورد با بخش‌های متن (تشابه عنوان + مدت).
۶. ساخت صفحه: هر بخش یک صفحهٔ تازه، پیشرَوی سطرها با ساعت صدا، متن ۳ سطری با اسکرول خودکار.

## دقت
پایداری با ۱۰ تنظیم مختلف پارامترها: میانگین ۰٫۲s، حداکثر ۱٫۲s. برای همگام‌سازی واژه‌به‌واژه
باید ASR فارسی اجرا شود؛ ستون `sentences` در `timing.json` نقطهٔ شروع آن است.
