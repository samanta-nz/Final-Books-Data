# ابزار زمان‌بندی گفتار ↔ وایت‌بورد

سه اسکریپت کوچک که محتوای وایت‌بورد (`NNNN.html`) را روی فایل صوتی همان درس (`NNNN.ogg`)
زمان‌بندی می‌کنند. ورودی هر درس: `.ogg` + `.txt` (متن گفتار) + (اختیاری) `.html` (وایت‌بورد).

```bash
pip install av numpy

# ۱) برای هر درس: زمان‌بندی بخش‌ها، جمله‌ها و اسلایدها -> NNNN.timing.json
python tools/slides_timing.py G09/G09-Math/F01/0101

# ۲) گزارش فارسی از همهٔ فایل‌های زمان‌بندی یک پوشه
python tools/make_report.py G09/G09-Math/F01

# ۳) دیدن پخش‌کنندهٔ همگام (باید از طریق http سرو شود، نه file://)
python tools/preview_server.py G09/G09-Math/F01 8099
#   -> http://localhost:8099/sync-player.html
```

## روش

۱. رمزگشایی ogg (vorbis/opus) به ۱۶ کیلوهرتز مونو و ساختن پاکت RMS با گام ۱۰ میلی‌ثانیه.
۲. آستانهٔ سکوت تطبیقی (صدک ۱۲ + ۳ دسی‌بل) → فهرست مکث‌ها.
۳. تقسیم متن به واحد جمله و دادن «وزن گفتاری» (تعداد حروف بی‌فاصله).
۴. پاس اول: نگاشت خطی وزن تجمعی روی «زمان باصدا»ی تجمعی (مکث‌ها حساب نمی‌شوند).
۵. برنامه‌ریزی پویا (DP) که مرز جمله‌ها را با هزینهٔ |اختلاف| روی مکث‌های واقعی قید می‌زند،
   سپس خط زمانی بین لنگرها تکه‌ای‌خطی بازسازی می‌شود (۳ تکرار، باند نزولی ۱۸→۲ ثانیه).
۶. تطبیق اسلایدهای `sc(...)` وایت‌بورد با بخش‌های متن: تقسیم‌بندی یکنوا با هزینهٔ
   تشابه عنوان + هم‌خوانی مدت با تعداد سطرهای اسلاید.

خروجی `NNNN.timing.json`:

```json
{ "base": "0101", "audio": "0101.ogg", "board": "0101.html",
  "stats": { "duration": 1679.04, "sentences": 310, "pauses": 608, ... },
  "sections": [{ "title": "...", "start": 39.33, "end": 94.54, "units": 12 }],
  "slides":   [{ "slide": 1, "title": "...", "start": 0.0, "end": 94.54 }],
  "sentences":[{ "t": 1.67, "sec": 0, "text": "..." }] }
```

## دقت

بدون تشخیص گفتار (ASR) کار می‌کند، پس «واژه‌به‌واژه» نیست:

* پایداری نتایج با ۱۰ تنظیم مختلف پارامترها: میانگین ۰٫۲ ثانیه، حداکثر ۱٫۲ ثانیه جابه‌جایی.
* خطای واقعی معمولاً چند ثانیه است؛ اگر متن `txt` با صدای خوانده‌شده اختلاف محتوایی داشته باشد
  (جملهٔ جامانده/اضافه) خطا می‌تواند تا ۵–۱۰ ثانیه هم برود.
* اگر متن هر درس دقیقاً همان چیزی باشد که خوانده شده (که در این مخزن همین‌طور به نظر می‌رسد)،
  مرز بخش‌ها روی مکث‌های واقعی می‌افتد و برای پرش سریع بین بخش‌ها کافی است.
* برای همگام‌سازی سطح خط/واژه باید ASR فارسی (مثل Whisper با مدل fa) اجرا و با همین خروجی
  ترکیب شود؛ ستون `sentences` همان‌جا نقطهٔ شروع است.
