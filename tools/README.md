# ابزار زمان‌بندی گفتار ↔ وایت‌بورد

زنجیرهٔ کار برای هر درس: `NNNN.ogg` + `NNNN.txt` (+ `NNNN.html` اگر وایت‌بورد دارد)
→ `NNNN.timing.json` → یک فایل مستقل `NNNN-sync.html` که صدا داخلش امبد است.

```bash
pip install av numpy

# ۱) زمان‌بندی: بخش‌ها، جمله‌ها و اسلایدها  ->  NNNN.timing.json
python tools/slides_timing.py G09/G09-Math/F01/0101
python tools/slides_timing.py G09/G09-Math/F01          # یا برای همهٔ درس‌های پوشه

# ۲) ساخت فایل تک‌فایلی همگام (صدا + وایت‌بورد + متن)  ->  NNNN-sync.html
python tools/build_sync.py G09/G09-Math/F01             # همهٔ درس‌ها + صفحهٔ فهرست sync-player.html
python tools/build_sync.py G09/G09-Math/F01/0101        # فقط یک درس
#   --original-audio : به‌جای Opus 32k، خودِ ogg اصلی را امبد می‌کند (فایل ~۲۱MB)

# ۳) گزارش فارسی زمان‌بندی  ->  timing-report.md
python tools/make_report.py G09/G09-Math/F01

# ۴) دیدن فایل‌ها از طریق http (اختیاری؛ فایل‌ها با file:// هم کار می‌کنند)
python tools/preview_server.py G09/G09-Math/F01 8099
#   -> http://localhost:8099/  (فهرست درس‌ها)
```

## چطور همگام می‌شود

**زمان‌بندی (`align_ogg.py`)** — بدون تشخیص گفتار:

1. رمزگشایی ogg (vorbis/opus) به ۱۶ کیلوهرتز مونو و پاکت RMS با گام ۱۰ میلی‌ثانیه.
2. آستانهٔ سکوت تطبیقی (صدک ۱۲ + ۳ دسی‌بل) → فهرست مکث‌ها.
3. تقسیم متن به واحد جمله با «وزن گفتاری» = تعداد حروف بی‌فاصله.
4. پاس اول: نگاشت خطی وزن تجمعی روی «زمان باصدا»ی تجمعی.
5. برنامه‌ریزی پویا مرز جمله‌ها را روی **پایان مکث** (لحظه‌ای که صدا دوباره شروع می‌شود) قید می‌زند؛
   خط زمان بین لنگرها تکه‌ای‌خطی بازسازی می‌شود (۳ تکرار، باند نزولی ۱۸→۲ ثانیه).
6. هر جمله بازهٔ `[t, end]` دارد؛ هایلایت در `t` عوض می‌شود (شروع جمله، نه پایانش).

**اسلایدها (`slides_timing.py`)** — عنوان و تعداد سطرهای `sc(...)` وایت‌بورد استخراج و با
بخش‌های متن به‌صورت یکنوا تطبیق داده می‌شود (تشابه عنوان + هم‌خوانی مدت با تعداد سطر).
بخشی که چند اسلاید دارد، بازه‌اش بین آن اسلایدها تقسیم می‌شود.

**صفحهٔ نهایی (`build_sync.py`)** — وایت‌بورد **داخل خود صفحه** رندر می‌شود (بدون iframe):

* پیشرَوی با ساعت صدا: در هر لحظه از هر بخش، می‌دانیم تا کدام سطر باید کشیده شده باشد
  (`(t - start) / (end - start) × تعداد سطر`) و سطرها یکی‌یکی و به ترتیب با صدا کشیده می‌شوند.
* وایت‌بورد **هیچ‌وقت خالی نمی‌ماند**: اولین سطر هر بخش همان لحظهٔ شروع بخش می‌آید (و در لحظهٔ
  بارگذاری هم صفحه خالی نیست) و هیچ چیزی پاک نمی‌شود؛ پس محتوای بخش قبل، تا شروع بخش بعدی می‌ماند.
* اگر کاربر جابه‌جا کند، صفحه فقط «جلو» می‌رود و چیزی پاک نمی‌شود؛ دکمهٔ ±۰٫۵s هم‌ترازی را
  تنظیم و در `localStorage` ذخیره می‌کند.

## دقت

* پایداری نتایج با ۱۰ تنظیم مختلف پارامترها: میانگین ۰٫۲ ثانیه، حداکثر ۱٫۲ ثانیه.
* خطای معمول نسبت به گفتار واقعی در حد چند دهم ثانیه تا چند ثانیه است؛ چون مرز جمله‌ها روی
  مکث‌های واقعی قید می‌شود، شروع هر جمله/بخش با شروع صدا هم‌تراز است.
* برای همگام‌سازی سطح واژه (زیرنویس دقیق) باید ASR فارسی اجرا شود؛ ستون `sentences` نقطهٔ شروع آن است.
* صدا در فایل نهایی به Opus 32k تک‌کاناله تبدیل می‌شود (حجم ۸MB به‌جای ۲۱MB). مرورگرهای
  کروم/فایرفاکس/اج خوب پخش می‌کنند؛ سافاری Ogg/Opus را پخش نمی‌کند (برای همان ogg اصلی هم همین‌طور است).
